# 🇮🇩 Cuti Kuy - Kalender Hari Libur Nasional Indonesia

Aplikasi kalender interaktif untuk melihat hari libur nasional dan cuti bersama Indonesia tahun 2026 & 2027 berdasarkan SKB 3 Menteri.

![Cuti Kuy Logo](/public/screenshoot-web-app.png)

## ✨ Features

- 📅 **3 View Modes**: Tahun (Year), Bulan (Month), Daftar (List)
- 🗓️ **Year Selector**: Ganti tahun kalender 2026 | 2027 dari header
- 💡 **Saran Ambil Cuti**: Rekomendasi hari cuti tahunan & cuti penghubung akhir tahun (termasuk libur 11 hari saat Natal/Tahun Baru) dengan tooltip interaktif
- 🌙 **Dark/Light Mode**: Smooth transition with dark mode as default
- 🔍 **Filter**: Libur Nasional, Cuti Bersama, atau Semua
- 🎨 **Color Coded**:
  - 🔴 Merah = Libur Nasional
  - 🟠 Kuning = Cuti Bersama
  - 🔵 Biru = Hari Ini
  - 🟢 Hijau = Saran Cuti
- 📱 **Responsive**: Works on desktop, tablet, and mobile
- 💝 **Trakteer Integration**: Support the developer

## 📝 Data Source

Hari libur nasional Indonesia 2026 & 2027 berdasarkan:

- SKB 3 Menteri (Kemenag, Kemenaker, Kemendikbud)
- Tanggal dapat berubah berdasarkan penetapan pemerintah
